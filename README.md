# Сладкая Жизнь

Локальная версия одностраничного сайта кондитерской в Люберцах.

## Запуск

Требуется Node.js. Из папки проекта:

```powershell
node server.mjs
```

Откройте `http://127.0.0.1:4173/` в браузере. Зависимости устанавливать не нужно.

Форма сохраняет заявки на этом компьютере в `data/orders.jsonl`. Папка `data/` исключена из Git. Для реального приёма заказов после публикации понадобится подключить способ доставки заявок владельцу. Демонстрационные названия и цены нужно подтвердить. Настоящие отзывы и контактный телефон пока не предоставлены.

Источники фотографий описаны в [IMAGE-SOURCES.md](IMAGE-SOURCES.md).
